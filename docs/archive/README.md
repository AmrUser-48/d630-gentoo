# Archived project documentation

## Overview

This directory preserves historical planning notes, checkpoints and earlier project documentation. It is an archive, not the current source of build or boot instructions.

## Status

Archived. Content may describe superseded paths, release tags, configurations or implementation plans. It is retained for provenance and comparison only.

## Layout

- `CHECKPOINT-*.md`: dated state snapshots and test checkpoints.
- `TODO-*.md`: historical task lists.
- `root-readme-pre-reorg-*.md`: previous root README snapshots.
- `legacy-iso-design.md`: an early ISO proposal; current optional ISO packaging is documented separately.
